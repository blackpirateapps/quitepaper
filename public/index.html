// Cryptographic Architecture

Zero-knowledge guarantees and security invariants.

Key Derivation & AEAD

  • Argon2id KDF: 19MB RAM, 2 iterations, 16-byte cryptographically secure random salt.
  • XChaCha20-Poly1305: 256-bit key, 192-bit (24-byte) random nonce, 16-byte Poly1305 MAC tag.
  • Separate Passwords: Firebase Auth password never decrypts notes or wraps master keys.

Database & Sync Invariants

  • Crypto-Blind Backend: Zero plaintext columns in Turso libSQL schema.
  • Offline-First SQLite: 100% operable offline with Drift SQLite local persistence.
  • Idempotent Delta Sync: Cursor-based revision log with conflict detection.

Editor & Local Storage

  • Canonical Markdown: Pure text model without AST document lock-in or proprietary JSON.
  • Hardware Keystore: Unlocked master keys secured in Android Keystore / iOS Keychain.
  • SAF Storage Access: Modern Scoped Storage compliance for .qpbackup files.
