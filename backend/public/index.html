Everything a writer needs.
Nothing they don't.

Zero-knowledge encryption

Note titles, bodies, and tags are encrypted on your device using Argon2id and XChaCha20-Poly1305 before they ever leave. The server holds ciphertext — nothing else.

Offline by default

Quiet Paper runs entirely from local SQLite storage. No connection required. Sync is an optional layer on top — not a dependency your writing relies on.

Markdown-native editor

Write in Markdown and switch to WYSIWYG visual mode anytime. Headings cycle, selections are preserved, and the formatting toolbar stays out of the way until you need it.

Reliable autosave

Changes are flushed on a 700ms debounce, on focus change, and on exit — silently, without prompts. Empty drafts are discarded automatically. You never manage saving.

Cross-device sync

Cursor-based delta sync keeps all your devices in agreement with conflict detection built in. Password rotation re-wraps your master key without re-encrypting notes.

Markdown folder import

Import entire folder hierarchies of .md files. Subfolder names become tags, YAML frontmatter metadata and timestamps are preserved, and duplicates are handled gracefully.

Questions people ask

Is Quiet Paper really free? +
Yes. The app and all core features — writing, offline storage, tagging, Markdown, local backup — are completely free. Cloud sync uses a small serverless backend; if infrastructure costs grow significantly, a fair optional subscription may be introduced in future, but nothing is paywalled today.
What does "zero-knowledge" actually mean here? +
It means the server never receives your note content in readable form. Encryption happens on your device before any network request is made. The database table that stores notes has no title, body, or tags columns — only encrypted ciphertext blobs. Even if the server or its database were compromised, an attacker would find nothing readable.
What happens if I forget my encryption password? +
During sync setup you are given a recovery key — a long random string that can unlock your encrypted vault without your password. Store it somewhere safe. If you lose both your password and your recovery key, your encrypted data cannot be recovered. This is an intentional property of the encryption design, not a limitation to fix.
Is the encryption password the same as my login password? +
No, and this is important. Your account password (managed by Firebase) answers the question "who are you?" Your encryption password answers "can you read your notes?" Resetting your account password — or losing it — does not affect your ability to decrypt notes. Changing your encryption password re-wraps your master key but does not re-encrypt your existing notes.
Can I import from Obsidian, Bear, or Notion? +
Yes, for any tool that can export to Markdown files. The Markdown folder importer handles arbitrary folder depths, YAML frontmatter, inline hashtags, and file timestamps. Obsidian vaults and Bear exports (via .md export) import well. Notion exports require converting to Markdown first — Notion's built-in "Export as Markdown" works for this.
Does Quiet Paper work without an internet connection? +
Completely. All notes are stored locally in SQLite. You can write, edit, search, and organize notes with no network access at all. If sync is enabled, changes made offline are queued locally and pushed automatically when a connection is next available — with conflict detection to handle edits made on other devices in the interim.
Which Android versions are supported? +
Quiet Paper targets Android 7.0 (API 24) and above. Four APK builds are published per release — arm64-v8a (most modern phones), armeabi-v7a (32-bit legacy devices), x86_64 (Chromebooks and emulators), and a universal fallback. The in-app updater selects the right binary for your device automatically.
Is there an iOS or desktop version? +
Not yet. iOS and desktop (macOS, Linux) releases are on the roadmap. The codebase is Flutter, so the architecture supports multi-platform builds — it's a matter of platform-specific work for things like Keychain integration, filesystem access, and keyboard navigation. Follow the GitHub repository for updates.
