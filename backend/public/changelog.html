Version 1.5.7 Beta Release September 4, 2026

Interactive WYSIWYG Editor V4 & Smart Checklists

f3aae62 6384782 c7141dd cce4251 Editor V4 Checklists Markdown
Why it matters

Most note apps either force raw Markdown with ugly syntax markers or adopt heavy proprietary document formats (like Quill or ProseMirror) that break offline file portability and risk data corruption. Quiet Paper solved this with Editor V4: a dynamic semantic projection layer where Markdown remains the 100% single canonical data store, but headings, checklists, and inline formats render visually as you write.

  • Interactive Phosphor Checklists: Interactive - [ ] checkboxes rendered with custom vector glyphs. Tapping immediately strikes through completed items and toggles Markdown state in place with smooth haptic feedback.
  • Smart Enter & Backspace Flow: Pressing Enter on an active task automatically creates a new task; pressing Enter on an empty checklist cleanly terminates the list without manual editing.
  • Sentence-Wide Inline Coalescing: Formatting across word boundaries and whitespaces (e.g. bolding an entire clause) coalesces smoothly into a single unified visual span without delimiter leaking.
  • Keyboard & Caret Invariants: Selecting headings or toggling styles never hides the virtual keyboard or resets caret position, preserving the writing flow.
Version 1.5.6 — Dictation Engine Stable September 2, 2026

Zero-Cloud On-Device Speech-to-Text with FUTO Models

857ea94 6851b32 67fa332 Speech Recognition On-Device AI Privacy Invariant
Why it matters

Almost all mobile voice dictation sends unencrypted audio snippets to remote corporate servers for inference. For a zero-knowledge, privacy-first notes app, that is an unacceptable compromise. Quiet Paper embedded on-device ONNX neural speech recognition (Sherpa-ONNX + FUTO models) that processes audio locally using the device's own hardware with zero network traffic.

  • Zero Network Footprint: Audio never leaves the local sandbox. You can dictate entire journals on airplane mode with zero connectivity.
  • Dual Keyboard Dictation: Kept the software keyboard active during speech capture, so users can seamlessly edit words, fix typos, or insert punctuation while speaking.
  • Floating Speech Bar: Designed a minimal 44dp recording toolbar showing real-time audio waveforms, elapsed timer, live transcribed tokens, and one-tap cancellation.
  • Multi-Model Architecture: On-demand model manager supporting fast English models (~40MB) and multilingual models with automatic speech language detection.

Knowledge Architecture Feature August 28, 2026

Bi-Directional Note Linking ([[Note]]) & Backlinks Graph

87036ce f970936 86a57f0 Zettelkasten Backlinks Autocomplete
Why it matters

Ideas thrive on connections. By adopting the standard double-bracket syntax ([[Link]]), Quiet Paper enables associative thinking similar to Roam and Obsidian, but renders backlinks in an elegant two-line editorial drawer at the foot of each document.

  • Notion-Style Inline Autocomplete: Typing [[ triggers a floating search popup that queries SQLite titles in real time, inserting links with a single tap.
  • Derived Relationship Graph: Links are parsed dynamically from note contents into an indexed SQLite virtual table, eliminating manual link management.
  • Expandable Backlinks Drawer: Notes display incoming references in an editorial tray showing surrounding snippet context without cluttering the main sheet.
  • Tablet 3-Pane Preservation: Clicking a linked note smoothly loads into the editor view without popping route history or turning tablet split-views blank.
Version 1.5.5 Stable August 20, 2026

Living Typography Engine & On-Demand Font CDN

d7a1241 b5c0c28 f373faa Typography iA Writer Quattro CDN Delivery
Why it matters

Typeface is the voice of the written word. Packaging high-quality font families directly inside the APK added over 20MB of dead weight. Quiet Paper implemented an on-demand CDN delivery system that downloads fonts with cryptographic hash verification only when chosen by the user.

  • iA Writer Quattro & SF Pro: Added legendary writing typefaces including iA Writer Quattro (the iconic hybrid duospace) and Apple SF Pro with automatic optical sizing.
  • 20MB+ APK Footprint Reduction: Bundled fonts are streamed dynamically from verified edge storage, keeping the download package nimble and fast to install.
  • Full UI Typography Sync: Font selections can be set exclusively for note editing or propagated globally across the entire interface and PDF exports.
  • Dual Theme Families: Formalized Classic Paper (Warm terracotta on soft parchment) and Warm Paper / Midnight (Serene slate blue on cool paper).

Material Design cards create heavy visual boxes and disjointed padding. Quiet Paper migrated its middle list pane into an uninterrupted, flowing river of paper inspired by Bear Notes. Note titles, clean previews, document badges, and timestamps sit harmoniously on the canvas.

Version 1.5.4 Security August 4, 2026

Android Scoped Storage SAF Backups & Rolling Archives

505dbf0 796de96 SAF Integration Encrypted .qpbackup Auto Rolling
Why it matters

Android 11+ Scoped Storage broke legacy POSIX file creation outside app-private directories. Users need true data sovereignty: the ability to export their notebooks to external SD cards, Google Drive, or local storage without OS permission failures.

  • Storage Access Framework (SAF): Implemented native ACTION_CREATE_DOCUMENT intents, letting users stream .qpbackup files directly into any system folder.
  • Client-Side Argon2id Encryption: Backups can be unencrypted JSON or wrapped in Argon2id + XChaCha20-Poly1305 envelopes protected by your personal password.
  • Automated Daily Rolling Backups: Executes silent non-blocking snapshots every 24 hours with automatic pruning (retention limit of 3, 5, 10, or 30 files).
  • Three Restore Modes: Smart Merge (keeps newer edits), Keep Both (re-UUID with restored tags), or Clean Replace (exact notebook snapshot).
